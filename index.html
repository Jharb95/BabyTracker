Live sync

Sync is off. Entries stay on this phone.

Everything lands in one Google Sheet that you own. Set it up once, then send the invite to the other phone.

  1. Make a new Google Sheet — name it whatever you like.
  2. Extensions → Apps Script. Delete what's there, paste in Code.gs.
  3. Change SECRET at the top to a phrase only you two know. Save.
  4. Deploy → New deployment → Web app. Execute as Me, access Anyone. Authorize it.
  5. Copy the /exec URL it gives you and paste it below with the same phrase.

Send the invite code, or bake it into the page: copy the line for index.html, paste it over the BUILT_IN_SYNC line near the top of the file, and re-upload. After that anyone who opens the page is connected already.

Anyone with the invite code can read and add entries, so send it to her and no one else.
